# Estrellas y sistemas

- `star.py` y `remnant.py`: estado de estrellas activas y remanentes.
- `stellar_model.py`, `hybrid_stellar_model.py`, `sevn_model.py` y
  `popiii_hassan_model.py`: interfaz y fuentes de evolución estelar.
- `star_formation.py`: nacimientos estelares según la cosmología del universo.
- `systems/`: formación, órbitas y registro de sistemas estelares.
- `data/stellar_tracks/popiii/`: datos locales del track Hassan; el modelo y
  `extraer_track_hassan.py` los buscan aquí.

Estos archivos solo cambiaron de ubicación. Las propiedades físicas y las
reglas de formación no se modificaron al ordenarlos.
